# 🐾 Desktop Pet (Shimeji Style)

귀여운 데스크톱 펫 애플리케이션입니다. 화면 위를 자유롭게 걸어 다니고, 바닥에 앉아 쉬거나 점프하며, 마우스로 잡아서 던질 수 있습니다!

**🌟 NEW: 연예인(아이돌/배우), 반려동물, 실사 인물 사진 완벽 지원!**

---

## 🚀 빠른 시작 (Quick Start)

### 🪟 Windows 사용자
1. `run.bat` 파일을 더블 클릭합니다.
2. 가상환경 생성 및 의존성(`PyQt6`, `Pillow`) 설치 후 펫이 자동으로 화면에 나타납니다.

### 🍎 macOS / 🐧 Linux 사용자
터미널에서 아래 명령을 실행하거나 `run.sh`를 실행합니다:
```bash
./run.sh
```

---

## 📸 연예인 및 실사 인물 사진 적용하기 (Celebrity Photo Support)

좋아하는 아이돌, 연예인, 친구, 반려동물의 사진(JPG, PNG, WebP)을 준비한 후 파이프라인을 실행합니다:

```bash
# 기본 실행 (자동으로 실사 사진을 감지하여 배경 제거 + 스티커 테두리 적용)
python3 asset_pipeline.py idol_photo.jpg

# 강제로 실사 모드 지정 및 스티커 테두리 두께 조절 (예: 4px)
python3 asset_pipeline.py idol_photo.jpg --mode photo --stroke-width 4

# 스티커 테두리 없이 원본 실사만 깔끔하게 적용하고 싶을 때
python3 asset_pipeline.py idol_photo.jpg --no-stroke
```

### 🌟 실사 사진 처리의 특장점
1. **AI 인물 누끼 (`rembg` 지원):**
   - 복잡한 무대, 일상, 공항 배경 속에서도 인물 경계(머리카락, 옷깃)를 분리합니다.
2. **화이트 스티커 테두리 (Sticker Stroke):**
   - 어둡거나 화려한 컴퓨터 바탕화면에서도 연예인의 얼굴과 머리카락이 묻히지 않고 또렷하게 돋보입니다.
3. **얼굴 왜곡 없는 자연스러운 모션 (Natural Bobble Motion):**
   - 만화 캐릭터처럼 얼굴이 찌그러지는 왜곡(Squash)을 방지하고, 자연스러운 보블(Bobble/Tilt)과 발걸음 바운스로 귀여운 아크릴 스탠드/스티커 느낌을 줍니다.

## 🎨 일반 캐릭터 이미지 적용하기

```bash
# 일반 만화 캐릭터 / 일러스트 이미지 적용
python3 asset_pipeline.py my_character.png
```

생성되는 프레임:
- `assets/idle/`: 4 프레임 (자연스러운 숨쉬기 호흡)
- `assets/walk/`: 8 프레임 (좌/우 보행 및 바운스)
- `assets/fall/`: 2 프레임 (공중 낙하)
- `assets/drag/`: 2 프레임 (마우스에 매달려 흔들림)
- `assets/sit/`: 2 프레임 (바닥 착지 휴식 및 zZ 수면)

## 🎮 마우스 조작법 & 기능

| 조작 | 기능 설명 |
| :--- | :--- |
| **마우스 좌클릭 + 드래그** | 캐릭터를 잡아 원하는 위치로 이동시킵니다. (`drag` 상태) |
| **마우스 릴리즈 (손 놓기)** | 마우스를 빠르게 움직이며 놓으면 관성으로 공중으로 던져집니다! |
| **마우스 우클릭** | 편리한 컨텍스트 메뉴 표시: |
| ↳ **🔍 크기 조절** | 1.0x (128px), 1.5x (192px), 2.0x (256px) 실시간 변경 |
| ↳ **➕ 펫 복제** | 화면에 새로운 펫 인스턴스를 추가 소환합니다. |
| ↳ **🪂 높이 띄우기** | 캐릭터를 하늘 높이 퐁 띄웁니다. |
| ↳ **📁 에셋 폴더 열기** | 현재 사용 중인 스프라이트 폴더를 엽니다. |
| ↳ **🔄 에셋 다시 불러오기**| 에셋 변경 후 앱 재실행 없이 즉시 새로고침 |
| ↳ **❌ 이 펫 닫기** | 개별 펫 창 닫기 |
| ↳ **🚪 전체 종료** | 모든 데스크톱 펫 종료 |

## ⚙️ 행동 상태 머신 (Behavior Probability)
바닥에 착지한 펫은 확률에 따라 다양한 행동을 취합니다:
- **Idle (40%):** 제자리에 서서 깜빡이며 호흡 (2.5 ~ 5초)
- **Walk (30%):** 좌우로 걸어 다님 (화면/작업표시줄 끝에 부딪히면 턴)
- **Sit (20%):** 바닥에 착지하여 zZ 수면
- **Jump (10%):** 힘차게 튀어올라 포물선 점프 후 착지
